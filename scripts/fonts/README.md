Fonts used only by `scripts/make-og.mjs` to set type in the Open Graph image.

- `BigShoulders-ExtraBold.ttf`: Big Shoulders (opsz 72, wght 800), SIL Open Font License 1.1. Source: Google Fonts.
- `JetBrainsMono-Medium.ttf`: JetBrains Mono (wght 500), SIL Open Font License 1.1. Source: Google Fonts.

The site itself loads fonts through `next/font`; these files are not shipped to the browser.
